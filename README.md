# makefun-monday-review

[![make.fun · u-zeroxfive-monday-reviewed-in-one-line-e55de3c1](https://make.fun/badge/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1.svg)](https://make.fun/competitions/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1)

One line reviewing my own Monday, as a one-star review: Monday showed up early, my coffee never arrived, and my inbox booked a meeting to discuss the delay. The program writes the line to `entry.txt` (UTF-8, 110 characters, no trailing newline).

> One star: Monday showed up early, my coffee never arrived, and my inbox booked a meeting to discuss the delay.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write it somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/monday-review-out python3 main.py
```
